# نور القرآن الكريم

## تشغيل الموقع على الكمبيوتر
1. ثبّت Python.
2. افتح CMD داخل مجلد المشروع.
3. نفّذ:
   `pip install -r requirements.txt`
4. ثم:
   `python noor_quran.py`
5. افتح: http://127.0.0.1:5000

## نشره على الإنترنت
1. ارفع ملفات المشروع إلى مستودع GitHub خاص أو عام.
2. أنشئ حساباً في https://render.com/
3. اختر New + ثم Blueprint، واربط مستودع GitHub الذي يحتوي render.yaml.
4. وافق على إعداد الخدمة والقرص الدائم.
5. بعد اكتمال النشر ستحصل على رابط HTTPS عام.

## ملاحظات مهمة
- القرص الدائم في إعداد Render مخصص لقاعدة SQLite حتى لا تضيع الحسابات والمفضلات عند إعادة تشغيل الخدمة.
- Render قد يغيّر خطته المجانية أو شروط الأقراص الدائمة؛ راجع السعر والتوفر الظاهرين في حسابك قبل النشر.
- لا تشارك SECRET_KEY ولا كلمات مرور المستخدمين.
- الموقع يستخدم خدمات خارجية لجلب نص القرآن والتفسير والصوت ومواقيت الصلاة؛ لذلك تحتاج هذه الميزات إلى اتصال بالإنترنت.
- قبل استخدام الموقع للجمهور، راجع مصادر النصوص والتفاسير والأذكار وتأكد من صحتها، واختبر جميع الصفحات.
